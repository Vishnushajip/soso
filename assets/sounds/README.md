# Sound assets

Drop the following files into this folder. They are loaded by `lib/core/services/sound_service.dart`. If a file is missing the player silently no-ops.

| File              | Trigger                  |
| ----------------- | ------------------------ |
| `sos.mp3`         | SOS Completed            |
| `point.mp3`       | Point Earned             |
| `win.mp3`         | Match Win                |
| `lose.mp3`        | Match Lost               |
| `friend_sent.mp3` | Friend Request Sent      |
| `friend_accept.mp3` | Friend Request Accepted |
| `notify.mp3`      | Notification Received    |
| `rank_up.mp3`     | Rank Promotion           |

Any short royalty-free clip works. Recommended sources:
- freesound.org (filter by CC0)
- pixabay.com/sound-effects
